# ESP8266 Wemos D1 mini — OTA Оновлення прошивки через веб-інтерфейс

Цей проєкт призначений для мікроконтролера **Wemos D1 mini (ESP8266)**. Він реалізує базовий вебсервер із підтримкою оновлення прошивки «по повітрю» (OTA — Over-the-Air) за допомогою зручного графічного веб-інтерфейсу бібліотеки **ElegantOTA**.

---

## 🚀 Можливості проєкту

* **Підключення до Wi-Fi**: Автоматичне підключення до вашої бездротової мережі в режимі станції (STA).
* **Головна вебсторінка**: Простий тестовий інтерфейс за стандартною адресою (`/`).
* **OTA-оновлення в один клік**: Інтерфейс за адресою `/update` дозволяє оновлювати прошивку пристрою безпосередньо через браузер за допомогою компільованого файлу `.bin`.

---

## 🛠 Апаратне та програмне забезпечення

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
Проєкт використовує такі бібліотеки:
* `ayushsharma82/ElegantOTA` (для інтерфейсу оновлення)
* Вбудовані бібліотеки ядра ESP8266 (`ESP8266WiFi`, `ESP8266WebServer`)

---

## 📂 Конфігурація проєкту (`platformio.ini`)

```ini
[env:wemos_d1_mini]
